2B1Q – Multilevel Coding

English Explanation

2B1Q = 2 Binary bits → 1 Quaternary signal element. Group the data into pairs. For each pair, choose the output voltage from the table using the sign of the previous signal level.

MLT-3 – Multiline Transmission, Three Levels

English Explanation

MLT-3 uses +V, 0, −V. A 0 means stay at the current level. A 1 advances one step through the cycle 0 → +V → 0 → −V → 0.

الشرح بالعربي

PCM – Quantization & Binary Encoding

English Explanation

Convert sampled analog amplitudes to digital codes in this order: step size (Δ) → level index (i) → quantized value (Xq) → binary code → quantization error (Eq).

الشرح بالعربي

نحسب حجم الخطوة أولًا، ثم نحدد رقم المستوى المناسب لكل عينة، وبعدها القيمة التقريبية والكود الثنائي والخطأ الناتج عن التقريب.

Important source detail: Your slide gives the range −20 V to +20 V and the samples, but does not specify the number of levels L. This solver defaults to L = 16 as a clearly labeled practice assumption. Change L to match your actual exam question.

Lecture Formulas

Δ = (Xmax − Xmin) / L
i = round((X − Xmin) / Δ)
Xq = Xmin + i × Δ
Eq = Xq − X
m = log₂(L) bits per sample

To keep an index inside the available levels, the solver clamps i to [0, L−1]. Rounding ties use the usual mathematical half-up rule for nonnegative shifted indices. The slide's Δ/L + rounding-at-endpoints convention is reproduced; see caveat in results.
